# Command Centre — Unified Personal Control (Brain v2.3.0)

## Goal
One place to see and find everything stored locally: records, tasks↔events, reminders↔tasks, expenses/debts/inventory, notes/journal/content calendar.

## Features
- **Universal search** (`searchAll`) across `task, reminder, note, person, money, debt, stockItem, habit, journal, event, photo, instagramDraft, instagramPublication` — scored, ranked.
- **Tasks ↔ Events**: tasks with due dates appear alongside calendar events, sorted by `at/due`.
- **Reminders ↔ Tasks**: active reminders + open tasks grouped.
- **Expenses / debts / inventory**: recent money records, open debts, stock counts.
- **Notes / journal / Reels calendar**: notes + journal entries + content calendar (Reels grouped by `scheduledAt` date).
- **Pending actions**: combined open tasks, active reminders, and Reel drafts (`READY/AWAITING_APPROVAL/SCHEDULED/FAILED`) sorted by due date.
- **NL “find”**: “find my meeting notes from last week” → searchAll + Command Centre link.

Everything is local; no server query. Offline-first.
